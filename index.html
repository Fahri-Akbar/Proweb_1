Apa itu HTML?

Menurut W3Schools:

  • HTML adalah singkatan dari Hyper Text Markup Language.
  • HTML adalah bahasa markup standar untuk membuat halaman web.
  • HTML menjelaskan struktur sebuah halaman web.
  • HTML terdiri dari serangkaian elemen.
  • Elemen HTML memberi tahu browser cara menampilkan konten.
  • Elemen HTML memberi label pada bagian-bagian konten seperti "ini adalah judul", "ini adalah paragraf", "ini adalah tautan", dan sebagainya.

Apa itu elemen HTML?

Sebuah elemen HTML didefinisikan oleh tag pembuka, beberapa konten, dan tag penutup:
<tagname>Konten di sini</tagname>
